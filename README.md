# Coding Assessment Platform

A scalable backend for an online coding assessment platform inspired by HackerRank and LeetCode, built using Spring Boot.

## Features

- User Registration
- Password Encryption using BCrypt
- Bean Validation
- Global Exception Handling
- Layered Architecture
- PostgreSQL Integration

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok
